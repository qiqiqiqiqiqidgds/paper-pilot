## 二、主界面原型（对开视图）

### 2.1 整体布局

```
┌──────────────────────────────────────────────────────────────────────────┐
│  📄 PaperPilot    [上传 PDF] [论文库] [设置]      [⚡生成 PPT] [导出]   │
├──────────┬────────────────────────────┬─────────────────────────────────┤
│ 📚 文件库 │                            │ [拆解] [创新] [对比] [漏洞]    │
│          │                            ├─────────────────────────────────┤
│ ✓ A.pdf  │                            │                                 │
│   24 页  │      PDF 源文档            │     AI 分析结果                  │
│   92%    │     （可拖拽、可缩放）      │     （Markdown 渲染）           │
│          │                            │                                 │
│ ○ B.pdf  │      [联动高亮]            │     📌 摘要                     │
│   18 页  │                            │     本文提出一种…               │
│          │                            │                                 │
│ ○ C.pdf  │                            │     🎯 核心贡献                  │
│   31 页  │                            │     1. 提出 XXX 方法             │
│          │                            │     2. 在 YYY 上…               │
│          │                            │                                 │
│ + 上传   │                            │     🧪 实验                     │
│          │                            │     准确率 92.3%               │
│          │                            │                                 │
│          │                            │     [🔗 跳转到 PDF 第 3 段]     │
└──────────┴────────────────────────────┴─────────────────────────────────┘
                ← 拖拽分割条 50:50 →
```

### 2.2 顶部栏

| 元素 | 功能 |
|------|------|
| Logo + 名称 | 品牌识别 |
| 上传 PDF | 触发文件选择对话框 |
| 论文库 | 跳转到论文管理页（W7） |
| 设置 | API Key、模型选择、主题 |
| 生成 PPT | 触发 W6 功能，一键出汇报 |
| 导出 | 导出 Markdown / Word |

### 2.3 左栏（文件库 + PDF 渲染）

- **上方**：文件列表，展示文件名、页数、解析状态、相似度
- **下方**：PDF 渲染区域，使用 `pdf.js`，支持缩放、翻页、文本选择
- **联动**：右栏点"🔗 跳转到 PDF"时，左栏自动滚动 + 高亮

### 2.4 右栏（AI 分析结果）

- **Tab 栏**：4 个核心 Tab + 1 个动作 Tab
- **内容区**：Markdown 渲染，支持标题、列表、表格、代码块、引用块
- **每个段落**都有"🔗 跳转到 PDF"按钮（联动高亮用）

### 2.5 分割条

- 使用 `react-resizable-panels`
- 默认 50:50
- 可拖拽（30:70 ~ 70:30）
- 双击复位 50:50

## 三、5 个右栏 Tab 内容结构

### Tab 1：拆解（基础，所有 Tab 都依赖它）

```yaml
字段:
  摘要: 200-300 字概括全文
  研究背景: 1-2 段
  研究目标: 1 段，本文要解决什么问题
  方法: 详细描述
  实验: 数据集 + 结果
  结论: 1-2 段

提示词定位: 严格基于原文，不要编造
```

### Tab 2：创新点

```yaml
字段:
  核心创新:
    - 创新点 1（带原文出处页码）
    - 创新点 2
    - 创新点 3
  创新等级: 渐进式 / 显著 / 颠覆性
  适用场景: 在什么领域/任务上能用

提示词定位: 提炼 + 评级，引用原文支撑
```

### Tab 3：对比（W4 联网搜相关工作后启用）

```yaml
字段:
  本文方法: 简述
  相关工作:
    - 标题:
      年份:
      方法:
      优点:
      缺点:
      与本文关系:
  对比表:
    表格: 5-10 行对比
  本文相对优势: 1-2 段

提示词定位: 客观、突出差异化
```

### Tab 4：漏洞（W5 启用）

```yaml
字段:
  方法层面:
    - 局限性 1（实验设计 / 数据 / 假设）
  实验层面:
    - 局限性 1（baseline 不全 / 评估指标单一）
  写作层面:
    - 局限性 1（论证薄弱 / 复现性差）
  改进建议:
    - 针对每个局限性的可执行建议

提示词定位: 友好但诚实，避免过度吹毛求疵
```

### Tab 5：PPT（W6 启用）

```yaml
字段:
  标题: 自动生成
  大纲: 5-8 张幻灯片
  每页内容: 标题 + 要点 + 备注
  风格: 学术汇报 / 通俗介绍（可切换）
  模板: 简约 / 中科院 / IEEE

动作: 一键生成 PPT → 下载 .pptx
```

## 四、联动高亮方案（关键技术点）

### 4.1 目标效果

> 用户点击右栏"🔗 跳转到 PDF 第 3 段" → 左栏自动滚动到对应位置 → 该段落黄底高亮 3 秒后渐隐

### 4.2 技术实现路径

**方案 A：基于文本匹配（推荐，MVP 用）**

```typescript
// 伪代码
async function jumpToPdf(quote: string) {
  // 1. 在 PDF 全文中搜索 quote
  const positions = await pdfDoc.searchText(quote);
  // 2. 滚动到第一个匹配位置
  pdfViewer.scrollTo(positions[0]);
  // 3. 加黄底高亮 layer
  highlightLayer.add(positions[0], 'rgba(255, 235, 59, 0.5)');
  // 4. 3 秒后渐隐
  setTimeout(() => highlightLayer.fade(positions[0]), 3000);
}
```

- 优点：实现简单，2-3 天搞定
- 缺点：长 quote 搜索慢，跨段落 quote 匹配不准

**方案 B：基于 PDF 坐标（更精准）**

```typescript
// 后端解析 PDF 时，记录每段的 bounding box
{
  page: 3,
  bbox: { x: 100, y: 200, w: 400, h: 50 },
  text: "本文提出一种基于..."
}

// 前端根据 bbox 直接画高亮层
highlightLayer.addRect(bbox, 'yellow');
```

- 优点：精准，无匹配问题
- 缺点：后端解析时要保留坐标（PyMuPDF 可以做）

**决策**：MVP 用方案 A，W7 升级到方案 B

### 4.3 后端支持

LLM 返回时强制带原文引用：

```json
{
  "summary": "本文提出...",
  "quotes": [
    { "section": "摘要", "text": "...", "page_hint": 1 }
  ]
}
```

后端解析时同步记录每页文本 → page 映射，前端可以基于 page_hint 快速定位。

## 五、关键状态设计

### 5.1 空状态（首次进入）

```
┌────────────────────────────────────────────┐
│                                            │
│              📄                            │
│         欢迎使用 PaperPilot                │
│                                            │
│     上传一篇 PDF 论文，让 AI 帮你           │
│     读懂它、对比它、找出它的亮点和不足      │
│                                            │
│         [  + 上传 PDF  ]                   │
│                                            │
└────────────────────────────────────────────┘
```

### 5.2 上传中

- 顶部进度条 0-100%
- 状态文案：「解析中... → 正在拆解... → 正在联网搜相关工作...」
- 每个阶段预计时间提示

### 5.3 解析完成

- 右栏默认显示"拆解" Tab
- 左栏 PDF 自动定位到摘要页
- 顶部 toast 提示「解析完成 ✓」

### 5.4 错误状态

| 场景 | 提示 |
|------|------|
| PDF 加密 | "该 PDF 已加密，请先解密后上传" |
| 文件过大 (>50MB) | "文件超过 50MB，请压缩后重试" |
| LLM 超时 | "分析超时，请重试或换更短论文" |
| 联网失败 | "相关工作搜索失败，仅展示拆解结果" |

## 七、答辩时怎么讲

1. **开头**："我做的是一个论文伴读智能体，左边是源文档，右边是 AI 分析。"
2. **演示拆解**：上传一篇论文 → 现场看到右栏出现五段拆解
3. **演示联动**："看，点右边的引用，左边自动定位并高亮"
4. **演示多步**："它不只是 chat，它会自动联网搜相关工作，自动做对比"
5. **演示 PPT**：一键生成汇报 PPT，"原本要两小时，现在两分钟"
