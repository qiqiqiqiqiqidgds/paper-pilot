## 二、后端代码审查报告（子代理）

### P0-1 pytest 会清空真实 `backend/data/papers` 与 `data/ppts` —— 测试与真实数据目录零隔离

**根因链（四处叠加）：**

1. `backend/app/config.py:238` —— `settings = Settings()` 在 import 时固化为进程级单例；`data_dir` 默认 `./data`（config.py:87），`_anchor_relative_paths`（config.py:167-174）把相对路径锚定到 `backend/`，`.env` 里 `DATA_DIR=./data` 同样指向真实目录。
2. `backend/tests/conftest.py:21-28` —— 注入了一批 env，**唯独没有注入 `DATA_DIR`**。pydantic-settings 的 env var 优先级高于 `.env`，所以只要这里设 `os.environ["DATA_DIR"]=<临时目录>` 即可隔离——当前没设，测试进程的 `settings.data_dir` 就是真实数据目录。
3. `backend/tests/test_e2e.py:50-52` —— 测试代码直接把 `PAPERS_DIR/PPTS_DIR` 硬编码指向真实目录；`clean_data_dirs()`（test_e2e.py:159-181）对真实 papers 目录下除 `.gitkeep`/`test_samples` 外的所有条目执行 `shutil.rmtree`/`unlink`，并对 ppts 目录整目录清空，无任何日志。
4. `backend/tests/test_e2e.py:269-312` —— `E2ETestBase` 在 setUpClass/tearDownClass/setUp/tearDown 各调一次 `clean_data_dirs()`；所有 `test_e2e_*.py` 与 `test_robustness_fixes.py` 都继承该基类——一次完整 pytest 会把真实论文反复清空数十次。

**日志对号**：「已删除论文目录」来自 `app/utils/storage.py:103`（delete_paper）；「清理孤儿 PPT」来自 `storage.py:199`（cleanup_orphan_ppts，由 `main.py:83-88` 启动时和每 6 小时定期执行）。当 pytest 清空 papers 后，真实服务下次清理会把剩余真实 PPT 判为孤儿删掉——**二次放大**。

**修法**：conftest.py 在任何 `app.*` import 之前设置 `os.environ["DATA_DIR"] = str(tempfile.mkdtemp(prefix="paperpilot-test-"))`；`test_e2e.py:50-52` 改为从 `Path(settings.data_dir)` 派生；在 clean_data_dirs/delete_paper 里加「目标不在测试临时目录则 raise」双保险（`test_storage_cleanup.py:34-39` 是现成正面示范）。

### P0-2 服务器启动/定期清理会无差别删除超过 7 天的 PPT（即使论文还在）

- `app/utils/storage.py:201-205`（mtime 分支）+ `app/main.py:84,97-101`。用户 7 天前生成的 PPT 会在重启/定时任务后静默消失，前端保存的 download_url 404。**这是生产环境自身就会发生的数据丢失**。
- 修法：删掉「未孤儿但过期也删」分支，或改为默认仅清孤儿、`max_age_days` 可配置且默认不启用。

### P1（收尾前应修）

- **P1-1** `app/utils/proxy.py:47`：XFF 取最左段，公网部署下伪造请求头即可绕过 10/min 限流刷 LLM token。应从右往左取第一个非 trusted IP。
- **P1-2** `app/main.py:163-165` + `app/api/analyze.py:296-324`：SSE 断连取消依赖三层 BaseHTTPMiddleware 包装，取消传播语义脆弱；若失效会留下跑满 300s 的后台 LLM 任务白烧 token。建议改纯 ASGI 中间件并实测断连回归。
- **P1-3** `app/api/upload.py:45-68,102`：名为流式校验，最终仍 `b"".join` 整文件驻留内存（≤50MB），再 write+parse 双份。建议边读边写临时文件。
- **P1-4** `app/api/upload.py:203-250`：论文列表每次全量 json.loads 数 MB 的 text.json，论文多了会占满线程池拖慢热路径。建议 meta 单独落 meta.json。
